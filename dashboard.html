What is ForgeAI?
Understand what engines are and how the whole system works

ForgeAI gives you a set of AI engines — each one is a carefully written system prompt that turns Claude (or any other LLM) into a specialized expert for a specific job.

Think of it this way: normally, when you ask an AI to "write an ad," you get a generic result because the AI has no context about how to write a real, high-converting ad. An engine changes that. You paste the engine into a Project, and from that point on, every conversation in that project runs through a trained expert — not a general AI.

💡 You are not prompting an AI. You are activating a specialist. The engine is the training — your chat message is just the task you give to that specialist.

ForgeAI has 16 engines covering copywriting, ads, SEO, email, social media, video, music, business planning, Instagram growth, resume writing, and more. The ConversionOS Pipeline combines them all into one complete marketing system.

🏗️
How to Set Up a Project in Any LLM
Step-by-step setup for Claude, ChatGPT, and Gemini

A Project is a persistent workspace inside an LLM that remembers a system prompt across all conversations. This is where you paste the engine. Here's how to do it in the three most popular LLMs:

Claude.ai ⭐ Recommended
Projects → New Project → Project Instructions = paste engine here. Every chat in this project runs through the engine.
ChatGPT
My GPTs → Create GPT → Instructions = paste engine. Or use a new chat with Custom Instructions enabled.
Gemini
Gems → Create a Gem → Instructions = paste engine. Each Gem acts as a persistent engine session.
Setting Up on Claude.ai (Detailed Steps)
1
Go to claude.ai and click "Projects" in the left sidebar
You need a Claude.ai account. The free plan works, but Claude Pro gives much longer context and better results.
2
Click "New Project" and give it a name
Name it after the engine — e.g., "Copy Forge", "Ad Forge". This keeps things organised if you use multiple engines.
3
Click "Set project instructions" or "Edit project instructions"
This is the system prompt field. This is exactly where the engine goes.
4
Go back to ForgeAI, open the engine, click "Copy Engine Prompt"
The full engine prompt is now on your clipboard.
5
Paste it into the Project Instructions field and save
Do not add anything else here. The engine is complete as-is. Just paste and save.
6
Start a new chat inside the project
Every conversation you start inside this project now runs through the engine. Claude is now your specialist — give it your first task.
✅ One project per engine. Don't mix engines in the same project. Create a separate project for each engine you use — this keeps the AI focused and gives you the best results.

The 3-Step Workflow
How to go from engine to output every single time
1
Pick the right engine for your task
Want to write an ad? Use Ad Forge. Writing a blog post? SEO Forge. Building an email sequence? Email Forge. Each engine is purpose-built — use the right one for the right job.
2
Copy the engine prompt and paste it into your LLM Project
Do this once per engine. After that, just open the project and chat — the engine is always active.
3
Give the AI your brief and let it work
Each guide below tells you exactly what to type for your first message. The more context you give — your product, audience, goal — the better the output.
📌 Golden rule: The AI is only as good as the brief you give it. Tell it your product name, what it does, who it's for, and what result you want. Don't just say "write me an ad" — that's like hiring an expert and giving them zero information.
